# Escaped values

English | [简体中文](README.zh-Hans.md)

Less’s tilde string syntax emits literal text. This file keeps an old IE-specific filter as a syntax specimen, not a supported browser effect.

Run `npm run build -w @latte/less` at the root, then inspect `tooling/less/dist/avoidcompile`. See the [parent guide](../README.md). GPL-2.0-only.
