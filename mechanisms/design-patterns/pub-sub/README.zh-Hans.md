# 发布与订阅

[English](README.md) | 简体中文

> 对应英文版：2026-09-28。

让发布者独立于不断变化的监听器集合。

## 运行与观察

在仓库根执行 `npm ci`、`npm test`，结合回归用例阅读短实现。

## 阅读机制

从 [simple.js](simple.js) 开始。

订阅返回取消函数；派发时复制监听器列表，避免回调内取消订阅导致跳过下一个监听器。监听器异常会传播给发布者。

## 新旧方案的联系

Map 避免特殊对象键冲突；这个同步事件中心不承诺异步或分布式消息能力。

## 验证与来源

`npm test` 验证机制合同；浏览器入口由 `npm run test:browser` 验证。代码中的来源链接继续保留，[迁移清单](../../../docs/migration.zh-Hans.md) 提供原始版本入口。
