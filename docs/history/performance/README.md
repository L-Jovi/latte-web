Read [the original Chinese report](research/README.md), whose tracked version is dated **2019-10-25**, commit `1141ac9`; its linked WebPageTest run is dated 2019-02-27. These dates describe different artifacts, not a new measurement.

The report preserves its screenshots, problem framing and original timing calculations. `performance.timing` is the older API. Its labels such as “white screen” or complete load are not interchangeable with today's LCP/INP/CLS; `loadEventEnd` alone does not prove that the interface is usable. Historical diagnoses and averages are not rerun results. Read [the current observation lab](../../../examples/performance/README.md) for supported instrumentation and explicit missing-data handling.

Images remain report evidence in their original context, not reusable design assets. The original references remain in the report; linked services/results may no longer be available. Documentation checks validate local image links. No claim of current reproduction is made.
