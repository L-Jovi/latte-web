# Ecosystem changes and reasons to preserve mechanisms

English | [简体中文](ecosystem.zh-Hans.md)

Checked on 2026-09-28. Modern tools reduce repetitive work; handwritten code explains the mechanisms those tools encapsulate. Age alone does not decide educational value.

| Topic               | Classic entry                                   | Current comparison                                 | Trade-off                                                                                                                                                                                     |
| ------------------- | ----------------------------------------------- | -------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| React application   | class/connect/Immutable/Saga                    | Hooks/TypeScript/RTK/RTK Query                     | Keep the same Todo actions and route behavior. Modern Redux reduces manual action/cache plumbing; the classic version still exposes those boundaries.                                         |
| Build flow          | Grunt, Gulp, Babel, Webpack                     | Vite 8                                             | Keep task orchestration and dependency-graph lessons. Use Vite for small new applications; retain Webpack topics to inspect loaders, chunks and plugins.                                      |
| Components          | Repeated CRA/library shells                     | One Card/Button source; three outputs              | Compare Babel transforms with actual Webpack/Vite bundles and load each output. Storybook demonstrates the same real components.                                                              |
| Testing             | React 0.14/Enzyme/shallow examples              | Testing Library, Vitest, Playwright                | Historical cases preserve the old model. Current tests assert observable behavior and browser transitions rather than internal component structure.                                           |
| Rich text           | Selection/Range and Draft.js                    | Lexical                                            | Native cursor mechanisms remain essential. Draft demonstrates controlled immutable editor state; Lexical owns an editor state with commands/plugins. Both format and serialize the same text. |
| Network             | JSONP and old Fetch claims                      | Fetch, CORS, AbortController                       | Script execution and response reading have different trust boundaries. Cancellation is now explicit; all teaching endpoints are local.                                                        |
| GraphQL             | express-graphql, old Apollo, committed database | graphql-http, Apollo 5/4, graphql-ws, Prisma 7     | Separate HTTP fundamentals from persistent authenticated behavior. Seed/migrations reproduce the data; subscription publication follows the completed write.                                  |
| Browser interaction | Mouse/Touch Events, manual tracks and timers    | Pointer Events, Scroll Snap, native animation      | Keep the coordinate, threshold and easing arithmetic. Modern APIs reduce event-family duplication and animation lifecycle bookkeeping.                                                        |
| Performance         | Dated performance.timing research               | Navigation Timing, PerformanceObserver, Web Vitals | Preserve old evidence as dated research. Current instrumentation handles missing support and never relabels a historic result as a new benchmark.                                             |

The root lockfile pins stable versions. Compatibility adjustments and limits live in each README. No maintained third-party forks or ignored peer-dependency checks are introduced.

Primary references: [React class support](https://react.dev/reference/react/Component), [Redux migration](https://redux.js.org/usage/migrating-to-modern-redux), [CRA retirement](https://react.dev/blog/2025/02/14/sunsetting-create-react-app), [Vite releases](https://vite.dev/releases), [Apollo subscriptions](https://www.apollographql.com/docs/apollo-server/data/subscriptions), [Web Vitals](https://web.dev/articles/vitals).
