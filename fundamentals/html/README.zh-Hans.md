# HTML 语义

[English](README.md) | 简体中文

> 对应英文版：2026-09-28。

把页面读作有含义的结构，而不只是通用盒子的堆叠。

## 运行与观察

在仓库根执行 `npm ci`、`npm run dev`，打开 `http://127.0.0.1:4173/fundamentals/html/semantic.html`。

## 阅读机制

从 [semantic.html](semantic.html) 开始。

原来的文章布局展示标题、分区与相关内容。这是结构练习，不代表已完成全面无障碍认证。

## 新旧方案的联系

原生标题、按钮和链接自带语义与行为，使用通用容器时这些能力需要重新补齐。

## 验证与来源

`npm test` 验证机制合同；浏览器入口由 `npm run test:browser` 验证。代码中的来源链接继续保留，[迁移清单](../../docs/migration.zh-Hans.md) 提供原始版本入口。
