Inside one BFC, top and bottom margins overlap同一个 BFC 里，上下外边距会重叠

overflow: hidden makes each box a BFC of its own, so the margins no longer overlapoverflow: hidden 让每个盒子自成一个 BFC，外边距不再重叠

Box model: with no padding or border, border-box is the same size as the default content-box盒模型：没有内边距和边框时，border-box 和默认的 content-box 一样大

A BFC wraps around the floats inside itBFC 会包住里面的浮动元素

A BFC does not overlap a float beside itBFC 不和旁边的浮动元素重叠
